GITHUB
Automatische deploy vanaf pages wanneer er veranderingen zijn.
NB. Copieer alle src naar directory docs, van daaruit vindt deploy plaats!!!

----------------------------------
Eerste keer:

copieer alle source files naar directory src

npm install --save-dev parcel-bundler
npm init -y

npm run build
npm start

copieer de textfile naar de dist directory
cp spreekuur.txt ../dist/

Bij opnieuw runnen: 
  rm -rf node_modules/ package-lock.json
   
   
package.json:
  "name": "arbo-advice",
  "version": "1.0.0",
  "description": "",
  "scripts": {
    "start": "parcel src/index.html",
    "build": "parcel build src/index.html --public-url ./"
  },
  "keywords": [],
  "author": "",
  "devDependencies": {
    "cssnano": "^6.1.2",
    "parcel": "^2.12.0",
    "postcss": "^8.4.44"
  },
  "license": "ISC"
}
